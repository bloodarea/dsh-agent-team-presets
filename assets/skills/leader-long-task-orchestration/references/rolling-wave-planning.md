# Rolling-wave Planning：滚动式规划

## 规划原则

规划精度随工程事实逐步提高。长程任务启动时不需要预测全部实现细节。

- **当前轮次**：详细规划到可分派、可执行、可验收的工作项。
- **下一轮次**：明确目标、主要交付物、依赖和待决策事项。
- **远期轮次**：保留方向、预期结果和已知风险，待前序结果明确后细化。

## 每轮规划内容

每轮明确轮次 ID、目标、交付物、工作项及依赖、负责人或所需角色、验收条件、已知风险和待决策事项。任务尽量独立交付；只有存在明确依赖或资源冲突时才设置先后关系。

## 执行与计划更新

每轮结束后：
1. 核实工作项结果及验收证据。
2. 更新已完成、部分完成和未完成统计。
3. 记录新发现的技术事实、风险和决策。
4. 根据实际结果细化下一轮。
5. 检查后续计划是否符合用户批准的产品基线。

Team Task Board 管理本轮成员任务；Leader Todo 管理队长协调动作；`DELIVERY-PLAN.md` 记录跨轮次基线、路线图和验收。三者不复制完整清单。

## 重新规划

前序结果改变技术前提、发现新依赖或风险、原方案无法满足验收、工作范围变化时调整计划。在批准范围内调整实现顺序和技术方案，由队长记录原因。涉及产品目标、功能、界面、范围、兼容性承诺、预算或重大风险变化时，先提交用户裁决。

## 避免虚假精确

对尚未调查的远期阶段，标记为“方向性计划”“待验证”或“待细化”。不要提前编造详细任务、工期或验收结果。
